# Ralph ループ実行プロンプト

あなたはこのリポジトリで**自律研究ループの1イテレーション**を実行する。状態はすべてファイルにある。以下の手順に上から順に従うこと。パスはリポジトリルートからの相対。

## 原則

- **1回の実行で進めるタスクは1つだけ**。小さく確実に前進し、続きは次回に回す。
- 記憶や推測に頼らない。判断の根拠は必ずファイル（GOAL / RULES / PLAN / QUESTIONS / journal / theory 本体）から取る。
- 作業の痕跡（PLAN の更新と journal のエントリ）を残さずに終了しない。次のイテレーションはこれらと git log しか見ない。

## 手順

### 1. 実行前チェック

以下のどちらかに当たれば、研究を始めずに理由を1行で報告して終了する（ファイルの変更・コミットはしない）。

- **前回の PR が未マージ**：`gh pr list --state open --json number,title` で、タイトルが `[ralph]` で始まる PR が開いていれば終了する。`gh` が使えない・認証されていない場合はこのチェックを飛ばして先へ進み、その旨を今回の journal エントリに書く。
- **目標が未設定**：`grep -n 'TODO(human)' ralph/GOAL.md` が1件でも当たれば終了する。

### 2. 状況把握（必ず読む）

1. `ralph/GOAL.md` — 研究の目標と完了条件
2. `ralph/RULES.md` — 規約
3. `ralph/PLAN.md` — タスクバックログ
4. `ralph/QUESTIONS.md` — 人間への質問と回答
5. `ralph/journal/` — ファイル名の番号が大きい方から2〜3件
6. GOAL.md が指す成果物ディレクトリ（`theory/` 配下）— 現状の成果物（まだ無ければ GOAL.md の背景からリンクされた資料を読む）
7. `git log --oneline -15` — 直近のコミット

### 3. 完了判定

GOAL.md の「完了条件」をすべて満たしているか確認する。

- **満たしている場合**：新しい研究はしない。成果物の校閲パスを1回だけ行う——誤字・数式の整合・リンク切れの点検と、関係する `tools/<topic>/` の検査コマンド（各 README の「検査の実行」節）の再実行。直すものが無ければ journal に「完了状態を確認、作業なし」のエントリだけを書いて手順7へ。
- 満たしていない場合：次へ。

### 4. タスク選択

- QUESTIONS.md に、回答が書き込まれていて未反映の質問があれば、その反映を最優先タスクとする。
- PLAN.md の「必須」の未完了タスクから、他のタスクの土台になるものを優先して**1つ**選ぶ。必須が尽きていれば「発展」から選ぶ。
- PLAN.md の「必須」が空なら、GOAL.md の中心的な問いと完了条件をタスクに分解して PLAN.md に書くことを今回のタスクとする。
- journal と git log を見て、直前の実行と重複しないことを確認する。
- 選んだタスクが1イテレーションに大きすぎるなら、PLAN.md 上で分割してから最初の一片だけをやる。

### 5. 実行

- RULES.md の規約（配置・記法・検証）に従って研究・執筆する。
- 試行錯誤や途中計算は `idea/` に置き、確定した論理だけを `theory/` に置く。
- 閉じた式を出したら数値検算し、RULES.md が定める既知の結果との整合チェック（特別な極限・既知の場合への帰着など）を行う。
- 行き詰まったら無理に結論を出さない。詰まった内容と試したことを journal に書いて次回に回す。人間の判断が要る事項は QUESTIONS.md に追記し、別のタスクに移る。

### 6. 記録

- PLAN.md：完了したタスクにチェックを入れ、作業中に見つかった新タスクを適切な節に追記する。
- QUESTIONS.md：回答を反映した質問には「（反映済み）」を付ける。
- journal：`ralph/journal/` に**新しいファイルを1つ作る**。既存のエントリは書き換えない。ファイル名とフォーマットは RULES.md の「journal」節に従う。

### 7. コミットと終了

- 変更をコミットしてプッシュし、プルリクエストを作る（メッセージ規約・PR タイトル・ベースブランチは RULES.md の Git 節）。ブランチ名自体は実行環境の標準の流儀に従ってよい。
- 最後に、今回やったことと次回の推奨タスクを1〜3行で報告して終了する。
