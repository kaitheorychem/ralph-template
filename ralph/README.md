# Ralph ループ（自律研究ループ）

同じプロンプトを繰り返し与えるだけで理論考察が前に進む仕組み。エージェントの記憶には頼らず、状態（目標・バックログ・進捗）をすべてこのディレクトリのファイルとして持つ。

## ファイル構成

パスはリポジトリルートからの相対。

| パス | 役割 | 書き換える人 |
|---|---|---|
| [ralph/PROMPT.md](PROMPT.md) | 毎回の実行手順（ループ本体） | 人間 |
| [ralph/RULES.md](RULES.md) | 研究・執筆・検証・Git の規約 | 人間 |
| [ralph/GOAL.md](GOAL.md) | 研究目標と完了条件 | 人間 |
| [ralph/PLAN.md](PLAN.md) | タスクバックログ | エージェント |
| [ralph/QUESTIONS.md](QUESTIONS.md) | エージェントから人間への質問と回答 | 両方（質問はエージェント、回答は人間） |
| `ralph/journal/` | イテレーションごとの記録（1回1ファイル） | エージェント |
| `theory/` | 確定した理論（成果物） | エージェント |
| `idea/` | 下書き・途中計算・没案 | エージェント |
| `refs/` | 先行研究のローカルコピー・メモ | 人間 |
| `tools/` | 数値検算コード | エージェント |
| `CLAUDE.md` | ループ外の対話セッション向けの入口 | 人間 |

「人間」のファイルはループの外から方向を制御するためのもの。

## 新しいリポジトリを作るとき

未記入の箇所には `TODO(human)` という目印が入っている。`grep -rn 'TODO(human)' .` で一覧できる。

1. このテンプレートからリポジトリを作る。
2. [GOAL.md](GOAL.md) の `TODO(human)` をすべて埋める（背景・目標・中心的な問い・完了条件）。**1つでも残っているとループは何もせずに終了する。**
3. 必要なら [RULES.md](RULES.md) の「プロジェクト固有の規約」節に書き足す（記号の約束、既存結果との整合チェック、触ってはいけないファイルなど）。無ければ空欄のままでよい。
4. [PLAN.md](PLAN.md) の「必須」に最初のタスクを数個書いておく（空でもよい。その場合は初回イテレーションが GOAL から分解する）。
5. 先行研究があれば `refs/` に置き、GOAL.md の背景からリンクする。
6. ルートの README.md（研究リポジトリとしての説明）の `TODO(human)` を埋める。
7. PR のベースブランチを変える場合は RULES.md の Git 節を書き換える（既定は `main`）。

## セットアップ（ウェブ版 Claude Code のスケジュール）

スケジュールのプロンプトに以下を貼る：

> ralph/PROMPT.md を読んで、その手順に従って自律研究ループを1イテレーション実行してください。

プロンプト本体はリポジトリ内にあるので、指示を変えたいときはスケジュールを触らずファイルを編集すればよい。

## 運用上の注意

- **PR のマージがループの前提**。各実行はベースブランチから始まるため、前回の PR をマージしないと PLAN / journal の更新が次回に見えない。そのため、ループの PR（タイトルが `[ralph]` で始まる）が未マージで開いている間は、次の実行は何もせずに終了する（PROMPT.md 手順1）。内容を却下する場合も、journal のファイルだけ拾ってベースブランチに入れ、PR は閉じると記録が途切れない。
- 方向を変えたいときは GOAL.md か PLAN.md を直接編集する。エージェントへの指示は全部ファイル経由で行う。
- QUESTIONS.md に質問が溜まったら、各質問の「回答」欄に書き込む（次のイテレーションが拾う）。
- **終了**：GOAL.md の完了条件を満たすと、以後のイテレーションは校閲・保守モードに落ちる（PROMPT.md 手順2）。ほぼ何もしない実行が続くようになったらスケジュールを止めてよい。判定は緩めに設計してある。
- 完了後に問いを追加したいときは GOAL.md のコアに足す。ループは研究モードに復帰する。

## 由来

Ralph loop（Geoffrey Huntley）：同一プロンプトをエージェントに繰り返し与え、状態管理をリポジトリ内のファイルに外部化する手法。ここでは連続ループの代わりにスケジュールで駆動するので厳密には Ralph ループそのものではないが、「状態はファイル、プロンプトは不変、1回1タスク」という骨格は同じ。
