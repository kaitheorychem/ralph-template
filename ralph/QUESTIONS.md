# 人間への質問

エージェントは判断に迷った事項（方向転換・矛盾の発見・規約や GOAL の変更提案・行き詰まり）を末尾に追記し、回答を待たずに別のタスクへ進む。人間は各質問の「回答」欄に書き込んでコミットする。番号は「質問1, 質問2, …」と通しで振る（GOAL.md の問い Q1… と区別するため）。後のイテレーションがそれを優先して反映し（優先順位は PROMPT.md 手順3）、見出しに「（反映済み）」を付ける。

書式：

```markdown
## 質問1：質問の短い名前
- 質問:
- 背景・選択肢: （エージェントの推奨があれば書く）
- 関連: （journal・idea・reviews へのリンク）
- 回答:
```
